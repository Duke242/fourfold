# Fourfold

A shedding card game in the style of UNO, with original names, suits and card designs. Single-file HTML; open `index.html` in a browser.

- Play against 1–3 computer opponents
- Suits: Sun, Tide, Ember, Moon
- Action cards: Block (skip), Flip (reverse), +2, Shift (wild), Shift +4
- Call **Last card!** before playing your second-to-last card, or draw two
- Score to 100, 250 or 500 points

The in-game **Rules** button explains every card.
